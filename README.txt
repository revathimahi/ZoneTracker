ZONE TRACKER - build the APK with GitHub (no Android Studio needed)
1. Create a free account at github.com and a new repository (any name).
2. Upload ALL files and folders from this zip (keep the .github folder).
3. Open the repo > Actions tab > "Build APK" > it runs automatically (about 5 min).
   If it did not start: Actions > Build APK > Run workflow.
4. Open the finished run > Artifacts > ZoneTracker-APK > download and unzip.
5. Copy app-debug.apk to your phone, tap it, allow "install unknown apps", install.
6. Open Zone Tracker, allow Location (Precise). Turn phone Location ON, High accuracy.
Works on Android 7.0 and newer. Needs internet for map tiles.
