ZONE TRACKER - build the APK with Android Studio
1. Install Android Studio (free): developer.android.com/studio
2. Open > choose this ZoneTracker folder > Trust project. Wait for Gradle sync (needs internet first time).
3. Build > Build Bundle(s) / APK(s) > Build APK(s) > locate.
   File: app/build/outputs/apk/debug/app-debug.apk
4. Copy to phone, tap it, allow "install unknown apps", install. Allow Location (Precise).
Works on Android 7.0+. Map library is bundled; only map tiles need internet.
